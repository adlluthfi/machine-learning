Tentang Aplikasi

🎯 Tujuan Aplikasi

Aplikasi ini dirancang untuk memberikan prediksi kesehatan menggunakan algoritma Machine Learning Gaussian Naive Bayes. Sistem ini dapat membantu dalam deteksi awal penyakit dan gangguan kesehatan.

📊 Model yang Tersedia

  • Diabetes Predictor: Memprediksi risiko diabetes berdasarkan data metabolik
  • Blood Test Analyzer: Menganalisis hasil tes darah untuk diagnosis
  • Sleep Disorder Detector: Mendeteksi gangguan tidur berdasarkan pola tidur

🔬 Metodologi

Semua model menggunakan algoritma Gaussian Naive Bayes yang dilatih dengan data kesehatan berkualitas tinggi. Model telah divalidasi dan menunjukkan akurasi yang baik.

⚠️ Disclaimer

Aplikasi ini adalah untuk tujuan edukatif dan tidak menggantikan konsultasi medis profesional. Selalu konsultasikan dengan dokter untuk diagnosis dan perawatan yang akurat.

📈 Fitur Aplikasi

  • ✅ Prediksi real-time menggunakan model terlatih
  • ✅ Dashboard dengan metrik performa model
  • ✅ Test akurasi dengan data aktual
  • ✅ Interface yang user-friendly
  • ✅ API endpoint untuk integrasi

💻 Teknologi yang Digunakan

  • Backend: Python Flask
  • Frontend: HTML5, CSS3, JavaScript
  • Machine Learning: scikit-learn
  • Database: JSON untuk metadata model
